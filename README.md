# Portaria Inteligente
## Introdução
Projeto desenvolvido ultilizando Web Server , Visão computacional e IA para a gestão inteligente de portaria de prédios e condomínios.

## Tecnologias usadas

Python , C# , Django ,APS.Net,Docker , HTML , CSS , JS e Bootstrap

## Desenvolvimento 

**Observação:** O foco desse projeto é apresentar o meu conhecimento no backend e comunicação de microserviços, assim o front-end foi criado como um serviço mínimo que apenas sirva para usar e testar o back-end. Logo fique a vontade para editá-lo ou criar um do zero, pois a maior atenção está no back-end.
